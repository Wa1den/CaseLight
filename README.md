# CaseLight

*[English](README.en.md)*

Подсветка внутри корпуса воспроизводит изображение с экрана. Управление устройствами идёт
через [OpenRGB](https://openrgb.org): плата, ленты и вентиляторы на её разъёмах, видеокарта,
память.

Windows, x64, .NET 9.

![Окно CaseLight: слева настройки, справа план с фигурами вокруг прямоугольника монитора](pics/interface.jpg)

## Принцип размещения

Корпус стоит рядом с монитором, поэтому изображение можно продолжить за пределы экрана.
В программе задаётся план: прямоугольник монитора, а вокруг него, в миллиметрах,
прямоугольники всех подсвеченных устройств. Каждый диод получает цвет с ближайшего к нему
участка экрана. Для точки за пределами панели координата зажимается к кромке, поэтому
вентилятор справа от монитора воспроизводит его правую кромку на своей высоте, а лента
по низу корпуса воспроизводит нижний край.

План собирается мышью: перетаскивание, изменение размера за угол, поворот.

## Требования

* Windows. Сборка идёт под SDK 10.0.22621, то есть Windows 11 22H2; на Windows 10
  не проверялось.
* [.NET 9 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/9.0)
* OpenRGB с поддержкой ваших устройств.

За совместимость с оборудованием отвечает OpenRGB. CaseLight работает с тем, что тот отдаёт
по SDK, и ограничен его списком поддерживаемых контроллеров.

Путь к OpenRGB.exe определяется автоматически по каталогам `Program Files\OpenRGB`,
`%LocalAppData%\Programs\OpenRGB` и записям об удалении в реестре; запуск выполняется
с ключами `--server --startminimized`. Путь можно указать и вручную. Если OpenRGB запущен
отдельно, в его настройках требуется включённый SDK-сервер, иначе порт 6742 закрыт.

## Установка

Готовый exe находится в [релизах](https://github.com/Wa1den/CaseLight/releases). Сборка из
исходников:

```
dotnet publish src/CaseLight/CaseLight.csproj -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o dist
```

## Настройка

1. Создайте фигуру для каждого подсвеченного устройства. В фигуре указывается контроллер,
   зона и диапазон диодов внутри зоны.
2. Разместите фигуру на плане в соответствии с положением устройства относительно монитора.
   Размеры монитора задаются по видимой части панели: у 27" 16:9 это примерно 597 на 336 мм.
3. Выберите форму раскладки: полоса, замкнутый контур (круглый или прямоугольный) или точка
   для устройства, которое светится целиком.
4. Для замкнутого контура назначьте начальный диод. Соседняя кнопка зажигает только
   выбранный диод, что позволяет определить нижний визуально.
5. Для вентиляторов, обращённых к наблюдателю ребром, включите отметку «с торца». Кольцо
   в этом случае сводится к вертикальной линии.
6. Проверьте раскладку тестом размещения: по холсту перемещается пятно, заменяющее собой
   кадр экрана.

Для проверки на настоящем кадре в `pics/Rainbow.jpg` лежит изображение с насыщенными
цветами во всех частях кадра. Установленное фоном рабочего стола, оно показывает
раскладку целиком: каждое устройство должно светиться цветом того участка экрана, около
которого стоит.

Количество диодов на ARGB-разъёме не определяется автоматически, разъём не передаёт эти
сведения, и OpenRGB подставляет значение 60. К одному разъёму при этом бывает подключено
несколько вентиляторов последовательно. Фактическая длина измеряется утилитой
`tools/RgbCalibrator`: кнопка «плюс» увеличивает светящийся отрезок на один диод, искомое
значение определяется по моменту, когда отрезок перестаёт расти.

Радиус выборки задаёт размер участка экрана, усредняемого для одного диода; по умолчанию
60 мм. При меньшем значении цвет заметно меняется от небольших движений в кадре, при
большем усредняется до однородного оттенка.

## Источник кадров

Собственный захват использует DDA и WGC одновременно и берёт наиболее свежий кадр; GDI
включается, если оба метода перестают выдавать кадры. Частота по умолчанию 30 кадров
в секунду.

Второй вариант: приём кадров от [Rimlight](https://github.com/Wa1den/Rimlight), подсветки
монитора. В этом случае экран захватывается один раз для обеих программ. Передача идёт
через разделяемую память, в Rimlight для этого включается отдача снимков.

Общий код обеих программ (захват, цветовой конвейер, выборка зон, шина кадров, слежение за
питанием) размещён в `src/CaseLight.Core` отдельной копией. Зависимости от Rimlight нет
намеренно: подсветка корпуса рассчитана в том числе на машину, где подсветки монитора нет.

## Скорость записи

У каждой фигуры задаётся делитель частоты обновления. Он нужен из-за памяти: модули
подключены по SMBus, запись туда выполняется медленно и на полной частоте задерживает
остальные устройства. Обновление несколько раз в секунду визуально не отличается от полной
частоты.

Устройство записывается целиком, иначе незаписанная часть погасла бы. Если на одном
контроллере расположено несколько фигур с разными делителями, применяется наименьший.

Одни и те же диоды могут относиться к нескольким фигурам. Три вентилятора, соединённые
параллельно, представлены в OpenRGB одним участком на 32 диода, а на плане занимают три
разных места. Цвета в этом случае усредняются.

## Права

Права администратора нужны только для памяти, поскольку доступ к SMBus без них закрыт.
Плата, вентиляторы и видеокарта доступны из обычной сессии, и тогда запрос UAC при входе
не появляется.

## Питание

Подсветка гаснет при выходе из программы, блокировке сессии, переходе в сон и отключении
монитора. Каждый из четырёх случаев настраивается отдельно.

После пробуждения запись в устройства откладывается. Контроллеры при выходе из сна
переподключаются к USB, OpenRGB продолжает запись в прежние дескрипторы и возвращает
признак успеха, при этом подсветка остаётся в состоянии, установленном при подаче питания.
По умолчанию сервер перезапускается, а первая запись выполняется через 8 секунд. Обе
величины настраиваются; вместо перезапуска доступно пересканирование устройств, но при нём
OpenRGB иногда аварийно завершается.

## Файлы

Раскладка, настройки и лог находятся в `%AppData%\CaseLight\`. Состояние программы целиком
хранится в `scene.json`, перенос на другую машину выполняется экспортом и импортом этого
файла.

## Инструменты

Каталог `tools` не входит в solution и собирается отдельно. Утилиты использовались при
выяснении доступных способов управления.

* `RgbProbe` выводит данные SDK-сервера: устройства, зоны, режимы, количество диодов.
* `RgbCalibrator` измеряет длину ленты на разъёме.
* `LampProbe` выводит устройства, доступные через HID LampArray средствами самой Windows,
  без OpenRGB.
